# Organizae

Aplicação web de gerenciamento de tarefas desenvolvida como trabalho prático individual.

## Descrição

O Organizae permite cadastrar, visualizar, editar, concluir e excluir tarefas diretamente pelo navegador.

A aplicação também possui filtros por status, contadores de tarefas e persistência dos dados utilizando localStorage.

## Funcionalidades

- Cadastro de tarefas
- Edição de tarefas
- Conclusão de tarefas
- Exclusão de tarefas
- Filtro de tarefas por status
- Contador de tarefas
- Definição de prioridade
- Definição de categoria
- Persistência dos dados com localStorage
- Interface responsiva

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` em um navegador.
3. A aplicação poderá ser utilizada diretamente no navegador.

## Decisões de implementação

As tarefas são armazenadas em uma lista de objetos JavaScript.

O localStorage é utilizado para manter os dados salvos no navegador mesmo depois que a página é fechada.

A interface foi construída sem frameworks, utilizando apenas HTML, CSS e JavaScript puro, conforme solicitado na atividade.
